Alumnium [v0.22][1] brings leaner accessibility trees, Cursor support, and new MCP session options. Available through [Maven Central][2], [npm][3], [PyPI][4], and [Docker][5].

## Leaner Accessibility Trees

Accessibility trees now use **20% fewer tokens on average** by removing redundant wrappers, compacting attributes, and collapsing repeated information. We also fixed tree caching within action steps and areas, and added web and mobile tree snapshots and evaluations.

Thanks to [Sasha Koss][6] for driving this work!

## Cursor and New Models

**Cursor** is now a supported provider, defaulting to `composer-2.5`:

```bash
export ALUMNIUM_MODEL=cursor
export CURSOR_API_KEY=<your-api-key>
```

Thanks to [Ish Abbi][7] for implementing it!

We also added Anthropic's fifth-generation models such as Fable along with GPT-5.6 models. See the [configuration guide][8] for setup.

The `github` provider was removed following its [retirement][11]. Switch to another provider before upgrading if you use it.

## MCP Improvements

Thanks to [Parameshwaran Murli][12], there are two new features in the MCP server.

### Device Emulation

The Playwright driver accepts a device preset or custom descriptor through `alumnium:options.device`, configuring the viewport, user agent, and touch settings:

```json
{
  "alumnium:options": {
    "device": "Pixel 7",
    "headless": true
  }
}
```

### Navigation Policies

Restrict browser navigation with `allowedDomains` and `deniedDomains` regular expressions. This example allows `example.com` and its subdomains:

```json
{
  "alumnium:options": {
    "navigationPolicy": {
      "allowedDomains": ["(^|\\.)example\\.com$"]
    }
  }
}
```


## Other Changes

- Launched a [new homepage][10].
- Improved automatic switching to tabs that open slowly in Playwright.
- Avoided clicking already-expanded dropdowns.
- Added scrolling elements into view before interaction.
- Fixed MCP session collisions when sessions start in the same second.
- Fixed element IDs returned by the server for locating elements.

## Coming Next

We're working on `alumnium test`, a CLI that runs tests written in Markdown. It uses AI to execute tests, then replays them deterministically with close-to-native performance.

Happy testing!
